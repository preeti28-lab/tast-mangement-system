# NexTask – Frontend

Next.js 16 (App Router) + Tailwind CSS v4 client for the Task Management System.

```bash
cp .env.example .env.local   # BACKEND_URL=http://localhost:5000
npm install
npm run dev                  # http://localhost:3000
```

See the [root README](../README.md) for the full setup, architecture and deployment guide.
